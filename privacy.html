PLUMORING AI · PRIVACY

Your data stays
your own.

This software research prototype has no physical ring or live sensor connection. Its analysis view accepts manually entered demo readings and can keep a local history in your browser.

Local histories

When you run Model 1, the page saves that snapshot, its experimental model/rule labels, and the time in this browser’s local storage. Chat messages are stored locally in the same way. Aggregate public-dataset result snapshots can also be saved in a separate research history; those summaries contain cohort metrics, not personal readings. Each history has Export and Clear controls. Stored histories remain on this device. Data are sent to OpenAI only when you choose an optional AI action, and only the information described in the relevant control is included.

Optional OpenAI requests

AI summaries and chatbot replies are optional. A summary sends up to 12 saved reading snapshots only after you press its button. Chat sends your message and recent conversation only after you press Send; readings are included only if you check that option. Requests go through this local server to the OpenAI API using a server-side key, with response storage disabled in the API request. OpenAI API policies and account settings apply. Never put a real key in frontend code or a public repository.

Analytics and other external services

The frontend does not include an analytics tracker or account system. It loads typefaces and 3D / animation code from public providers such as Google Fonts, unpkg, and esm.sh. Those providers and the site host may receive standard request metadata when your browser loads a page or asset; their own privacy terms apply.

Model and research limits

No validated pulmonary disease model is deployed. Model 1 returns uncalibrated telemetry-state classes; separate threshold rules are illustrative only. AI summaries and chat provide general education, not diagnosis, personal disease probabilities, or treatment. The current COPD exacerbation comparison is exploratory, uses non-ring data, and did not beat the no-skill reference.

Software research prototype · local browser history · optional, user-initiated AI requests · no live sensor or clinical workflow.
